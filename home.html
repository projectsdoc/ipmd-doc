IPMD-core

IPMD stands for Image Pixel Metadata

ipmd-core is a lightweight Python library that lets you embed important information (such as time and name) directly into the pixels of an image. This helps the data survive even when normal metadata is stripped by messaging apps like WhatsApp, Telegram, etc.

Current Support: Only _Time_ and _Name_ fields for now.
