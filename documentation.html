IPMD-core 📌

Author: Kelechi
Date: 04/11/2026

A simple way to pin information like dates and names directly into image pixels so it doesn't get lost when you send it to other devices or take a screenshot.

Core API

FunctionWork
RIPIA()Hide data inside image
.save()Save encoded image
RIPIAR()Load encoded image
.reveal()Extract data

CLI Commands

CommandMeaning
-ach / --anchorAdd info
-r / --retrieveGet info
-srcImage path
-infData
-rsrcEncoded image

IPMD Test Demo

Original Image (Without info)

File: original.png

Anchoring Data (Adding info)


from ipmd import RIPIA

image = "original.png"
data = {"_Time_": "|27/4/2026|", "_Name_": "Minimalist Human|"}

anchor = RIPIA(image, data)

print(anchor.save()) # auto save

Output:
Save successful: [original_ipmd.png]

IPMD Image (With info)

File: original_ipmd.png

Extracting Data (Retrieving info)


from ipmd import RIPIAR

ipmd_image = "original_ipmd.png"
extrat = RIPIAR(ipmd_image)

print(extrat.reveal())


[['|27/4/2026|minimalist human|'],
